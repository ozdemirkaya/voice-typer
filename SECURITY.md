# Security Policy

## Supported Versions

Currently, only the latest release of Voice Typer is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

We take the security and privacy of Voice Typer very seriously. 

If you discover a security vulnerability within this project, please **do not** disclose it publicly by creating a public GitHub issue.

Instead, please use **GitHub's private vulnerability reporting feature** (Security -> Advisories -> "Report a vulnerability"). 

We will acknowledge receipt of your vulnerability report and strive to send you regular updates about our progress. If a fix is implemented, we will coordinate a public disclosure and release.
